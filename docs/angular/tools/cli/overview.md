# Angular CLI {: #the-angular-cli}

:date: 30.09.2026

Angular CLI — интерфейс командной строки: из оболочки можно создать каркас приложения, разрабатывать его, тестировать, разворачивать и сопровождать.

Пакет публикуется в npm под именем `@angular/cli` и содержит исполняемый файл `ng`. Команды с `ng` — это и есть Angular CLI.

!!! info "Angular без локальной установки"

    Если Angular ещё не знаком, начните с [Попробовать сейчас!](https://angular.dev/tutorials/learn-angular): там основы разобраны на готовом учебном магазине, который можно изучать и менять.
    Этот самостоятельный учебник идёт в интерактивной среде [StackBlitz](https://stackblitz.com).
    Локальное окружение понадобится, только когда будете к нему готовы.

## Синтаксис языка команд CLI {: #cli-command-language-syntax}

Angular CLI в целом следует соглашениям Unix/POSIX для синтаксиса параметров.

### Логические параметры {: #boolean-options}

У логического параметра две формы: `--this-option` ставит флаг в `true`, `--no-this-option` — в `false`.
Можно писать и `--this-option=false` или `--this-option=true`.
Если параметр не передан, флаг остаётся в состоянии по умолчанию, как в справочнике.

### Параметры-массивы {: #array-options}

Массив задают двумя способами: `--option value1 value2` или `--option value1 --option value2`.

### Параметры ключ/значение {: #keyvalue-options}

Некоторые параметры, например `--define`, ждут массив пар `key=value`.
Как и массивы, их передают двумя способами:
`--define 'KEY_1="value1"' KEY_2=true` или `--define 'KEY_1="value1"' --define KEY_2=true`.

### Относительные пути {: #relative-paths}

Файлы в параметрах указывают абсолютным путём или путём относительно текущего каталога. Обычно это корень рабочего пространства или проекта.
