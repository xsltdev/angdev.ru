# Серверный и гибридный рендеринг {: #server-side-hybrid-rendering}

:date: 30.09.2026

Как ускорить приложение разными стратегиями отрисовки.

Для разработчика важно, чтобы приложение работало как можно быстрее. Эти руководства помогают собирать быстрые приложения и опираться на разные стратегии отрисовки.

| Руководства | Описание |
| :---------- | :------- |
| [Серверный и гибридный рендеринг](https://angular.dev/guide/ssr) | Как отрисовка страниц на сервере сокращает время загрузки. |
| [Гидратация](../hydration.md) | Процесс, который ускоряет приложение: после серверного рендеринга восстанавливает состояние и по возможности переиспользует уже готовое дерево DOM. |
| [Инкрементальная гидратация](https://angular.dev/guide/incremental-hydration) | Продвинутый вид гидратации: часть приложения остаётся без гидратации, а нужные участки гидратируются по мере необходимости. |
