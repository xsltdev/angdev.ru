# Селекторы компонентов {: #component-selectors}

:date: 30.09.2026

!!! tip ""

    Этот материал предполагает, что вы уже прочитали [руководство по основам](../essentials/overview.md). Если Angular для вас в новинку, начните с него.

Каждый компонент задаёт [CSS-селектор](https://developer.mozilla.org/docs/Web/CSS/CSS_selectors), который определяет, как компонент используется:

```ts
@Component({
  selector: 'profile-photo',
  ...
})
export class ProfilePhoto { }
```

Компонент используют, создавая подходящий HTML-элемент в шаблонах _других_ компонентов:

```ts
@Component({
  template: `
    <profile-photo />
    <button>Upload a new profile photo</button>`,
  ...,
})
export class UserProfile { }
```

**Angular сопоставляет селекторы статически на этапе компиляции.** Изменение DOM во время выполнения — через привязки Angular или через API DOM — не влияет на то, какие компоненты отрисованы.

**Элемент может совпасть ровно с одним селектором компонента.** Если с одним элементом совпало несколько селекторов, Angular сообщает об ошибке.

**Селекторы компонентов чувствительны к регистру.**

## Виды селекторов {: #types-of-selectors}

В селекторах компонентов Angular поддерживает ограниченный набор [базовых типов CSS-селекторов](https://developer.mozilla.org/docs/Web/CSS/CSS_Selectors):

| **Тип селектора**   | **Описание**                                                                                                      | **Примеры**                   |
| ------------------- | ----------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| Селектор типа       | Совпадает с элементами по имени HTML-тега, то есть по имени узла.                                                | `profile-photo`               |
| Селектор атрибута   | Совпадает с элементами по наличию HTML-атрибута и, при необходимости, по точному значению этого атрибута.        | `[dropzone]` `[type="reset"]` |
| Селектор класса     | Совпадает с элементами по наличию CSS-класса.                                                                     | `.menu-item`                  |

Для значений атрибута Angular умеет сравнивать точное значение оператором равенства (`=`). Другие операторы сравнения значений атрибута не поддерживаются.

Селекторы компонентов не поддерживают комбинаторы, в том числе [комбинатор потомка](https://developer.mozilla.org/docs/Web/CSS/Descendant_combinator) и [дочерний комбинатор](https://developer.mozilla.org/docs/Web/CSS/Child_combinator).

Селекторы компонентов не поддерживают [пространства имён](https://developer.mozilla.org/docs/Web/SVG/Namespaces_Crash_Course).

### Псевдокласс `:not` {: #the-not-pseudo-class}

Angular поддерживает [псевдокласс `:not`](https://developer.mozilla.org/docs/Web/CSS/:not). Его можно дописать к любому другому селектору, чтобы сузить набор элементов, с которыми совпадёт селектор компонента. Например, селектор атрибута `[dropzone]` можно ограничить так, чтобы он не совпадал с элементами `textarea`:

```ts
@Component({
  selector: '[dropzone]:not(textarea)',
  ...
})
export class DropZone { }
```

Другие псевдоклассы и псевдоэлементы в селекторах компонентов не поддерживаются.

### Сочетание селекторов {: #combining-selectors}

Несколько селекторов можно склеить в один. Например, так совпадут элементы `<button>` с `type="reset"`:

```ts
@Component({
  selector: 'button[type="reset"]',
  ...
})
export class ResetButton { }
```

Можно перечислить несколько селекторов через запятую:

```ts
@Component({
  selector: 'drop-zone, [dropzone]',
  ...
})
export class DropZone { }
```

Angular создаёт компонент для каждого элемента, который совпал с _любым_ селектором из списка.

## Выбор селектора {: #choosing-a-selector}

Почти всем компонентам в селектор стоит ставить имя пользовательского элемента. По [спецификации HTML](https://html.spec.whatwg.org/multipage/custom-elements.html#valid-custom-element-name) такое имя содержит дефис. По умолчанию Angular сообщает об ошибке, если встречает имя пользовательского тега, которому не соответствует ни один доступный компонент: опечатка в имени не проходит незаметно.

Как использовать [нативные пользовательские элементы](https://developer.mozilla.org/docs/Web/Web_Components) в шаблонах Angular, описано в [Расширенная настройка компонента](https://angular.dev/guide/components/advanced-configuration).

### Префиксы селекторов {: #selector-prefixes}

Команда Angular советует короткий общий префикс для всех пользовательских компонентов проекта. Если бы YouTube писали на Angular, компоненты могли бы начинаться с `yt-`: `yt-menu`, `yt-player` и так далее. По такому префиксу сразу видно, откуда компонент. Angular CLI по умолчанию ставит `app-`.

!!! warning ""

    Angular использует префикс селектора `ng` для собственных API фреймворка. Не берите `ng` как префикс селекторов своих компонентов.

### Когда нужен селектор атрибута {: #when-to-use-an-attribute-selector}

Селектор атрибута уместен, когда компонент нужно повесить на обычный нативный элемент. Например, свою кнопку можно построить поверх стандартного `<button>`:

```ts
@Component({
  selector: 'button[yt-upload]',
   ...
})
export class YouTubeUploadButton { }
```

Тот, кто использует компонент, сразу получает стандартные API элемента, без дополнительной обвязки. Это особенно важно для атрибутов ARIA, например `aria-label`.

Angular не сообщает об ошибке, если пользовательский атрибут не совпал ни с одним доступным компонентом. С селектором атрибута легко забыть импортировать компонент или его NgModule, и тогда компонент просто не отрисуется. Подробнее в разделе [Импорт и использование компонентов](anatomy-of-components.md#imports-in-the-component-decorator).

У компонентов с селектором атрибута атрибуты пишут в нижнем регистре через дефис. Префикс берут по той же рекомендации, что и выше.
